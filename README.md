# 🧵 Wijesinghe Textiles AI Assistant

> A multilingual AI-powered customer assistant designed to improve the customer experience at Wijesinghe Textiles through interactive digital assistance.

## 🤖 Overview

The **Wijesinghe Textiles AI Assistant** is a web-based chatbot designed to help customers access store information, navigate departments, and explore customer services through an interactive conversational interface.

The application provides a user-friendly experience with multilingual support and convenient access to essential store information.

## ✨ Features

- 🌐 **Multilingual Support** – English, Sinhala, and Tamil.
- 🏬 **Store Floor Guide** – Navigate store floors (Floors 01–05).
- ⚡ **Quick Actions** – Access frequently requested information quickly.
- 🔄 **Exchange Policy** – Explore store exchange policy information.
- 📍 **Branch Information** – Access branch-related information.
- 🏷️ **Offers Information** – Explore available offers.
- 💬 **Interactive Chat Interface** – A conversational customer support experience.
- 🌙 **Light & Dark Themes** – Switch between interface themes.
- 🏠 **Home Navigation** – Return to the welcome screen easily.

## 🚀 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Sandeepawijesinghe/textiles-ai-assistant.git
```

### 2. Navigate to the project directory

```bash
cd textiles-ai-assistant
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Environment Configuration

Configure the required environment variables using `.env.example` as a reference.

> ⚠️ Never expose API keys, passwords, or other sensitive credentials in a public repository.

### 7. Run the application

```bash
python app.py
```

Open the local URL displayed in the terminal to access the chatbot.
